About me

I build software, then check whether it actually works for the person using it.

My background covers software development for the web and for mobile. On the web I work mostly on the frontend. On mobile I build with React Native and Expo. Quality assurance sits next to that work: manual testing, clear bug reports, and enough documentation that a fix can be checked again.

I use AI-assisted development while implementing and reviewing code. It helps me move, and I still read the result and test the flow myself.

I am looking for software engineering work where building the product and caring about its quality are the same job.

  • Software developmentFunctional web and mobile applications.
  • Web applicationsInterfaces, flows, and the details that make a product usable.
  • FrontendReact, TypeScript, JavaScript, Vite, and Tailwind CSS.
  • MobileReact Native and Expo.
  • Quality assuranceManual testing, functional checks, and regression passes.
  • Bug reportingSteps, expected result, actual result, and a retest after the fix.
